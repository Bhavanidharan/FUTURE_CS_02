# Evidence — Screenshot Descriptions

This folder contains screenshots captured during the phishing email investigation as part of **Future Interns Cyber Security Internship 2026 — Task 02**.

All screenshots were taken using publicly available email header analysis tools: **Google Admin Toolbox Messageheader** and **MXToolbox**. They serve as evidence of the analysis performed to identify phishing indicators and verify sender authenticity.

---

## Screenshots

### 1. Google Admin Toolbox.png

This screenshot shows the analysis results generated by **Google Admin Toolbox Messageheader**. The tool was used to examine email authentication records and message metadata. The analysis revealed SPF failure, missing DKIM signatures, and DMARC failure, indicating that the sender could not be verified and the email was potentially spoofed.

**Tool:** [https://toolbox.googleapps.com/apps/messageheader/](https://toolbox.googleapps.com/apps/messageheader/)

---

### 2. MX Toolbox.png

This screenshot presents the overall email header analysis performed using **MXToolbox**. It provides a summary of email delivery information, authentication status, and compliance checks used to evaluate the legitimacy of the email.

**Tool:** [https://mxtoolbox.com/EmailHeaders.aspx](https://mxtoolbox.com/EmailHeaders.aspx)

---

### 3. MX Toolbox 2.png

This screenshot displays relay information and SPF record analysis. The investigation examined the sender IP address, email routing path, and SPF configuration to determine whether the sending server was authorized to send emails on behalf of the claimed domain.

**Tool:** [https://mxtoolbox.com/EmailHeaders.aspx](https://mxtoolbox.com/EmailHeaders.aspx)

---

### 4. MX Toolbox 3.png

This screenshot contains detailed SPF authentication validation results. The analysis identified SPF authentication failures and reviewed DNS record configurations, helping to verify the authenticity of the sender domain.

**Tool:** [https://mxtoolbox.com/EmailHeaders.aspx](https://mxtoolbox.com/EmailHeaders.aspx)

---

### 5. mx Toolbox 4.png

This screenshot shows the complete raw email header used during the investigation. The header contains routing information, sender details, authentication records, timestamps, and message identifiers that are essential for forensic email analysis.

**Tool:** [https://mxtoolbox.com/EmailHeaders.aspx](https://mxtoolbox.com/EmailHeaders.aspx)

---

### 6. MX Toolsbox 5.png

This screenshot displays extracted email header fields and metadata. Information such as sender address, reply-to address, subject line, authentication results, and message identifiers were reviewed to identify phishing indicators and assess the email's trustworthiness.

**Tool:** [https://mxtoolbox.com/EmailHeaders.aspx](https://mxtoolbox.com/EmailHeaders.aspx)
